# 0001. Технічна основа проєкту

Дата: 19 жовтня 2026. Статус: прийнято для локального каркаса.

## Завдання

Підготувати основу сервісу пошуку майстрів: маршрути, компоненти, структуру модулів і відтворювані перевірки. Відділити предметні дані й правила від відображення.

## Рішення та причини

| Рішення                               | Навіщо                                                                              | Компроміс                                                         |
| ------------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Next.js 16.4.2, App Router            | React зі сторінками за структурою файлів; надалі серверний HTML і серверні операції | Потрібно враховувати правила маршрутизації та межу server/client  |
| React 19.3.1, TypeScript 6.0.3 strict | Компонентна модель і перевірка контрактів даних                                     | Типи не заміняють перевірку введення на сервері                   |
| CSS Modules                           | Звичайний CSS з локальними назвами класів                                           | Компоненти оформлюємо самі, без готової UI-бібліотеки             |
| Biome 2.5.15 + Prettier 3.9.10        | Перевірка коду, JSX, правил React/Next і єдине форматування                         | Автоматичні правила не замінюють перевірку доступності в браузері |
| Node.js 24 LTS, npm, lockfile         | Підтримуване середовище й відтворювані залежності                                   | Оновлення перевіряємо перед прийняттям                            |
| app / modules / shared                | Зрозумілі місця для маршрутів, предметного коду й спільних частин                   | Не створюємо всі майбутні модулі наперед                          |

Версії звірено з npm 19.10.2026. Для lint обрано Biome з рекомендованими правилами React і Next.js: стандартний ESLint-набір Next.js залежав від плагінів до ESLint 9, підтримка якого вже завершилась. У Biome вимкнено форматування й автоматичне впорядкування імпортів, щоб за формат усіх файлів відповідав один Prettier. TypeScript 6.0.3 — зафіксована стабільна версія для цієї основи; перехід на наступну основну версію потребуватиме перевірки Next.js та інструментів. Не використовувати `--force` або `--legacy-peer-deps` для приховування конфліктів.

## Межі цього кроку

На момент прийняття рішення маршрути й компоненти мали статичні заготовки; актуальний стан реалізації описано в README. Системний стек шрифтів не потребує мережі; окрему гарнітуру з українськими символами можна обрати при оформленні реальних екранів. Палітра: білий і синій.

Метадані, `lang="uk"`, структура заголовків і навігація — початок технічного SEO та доступності, а не підтвердження всіх вимог WCAG чи місця в Google. До справжнього каталогу діють noindex і заборона обходу. Перед запуском переглянути обидва налаштування, додати перевірений домен, canonical і sitemap для дозволених сторінок. Приватні сторінки захищати серверною авторизацією незалежно від пошукових правил.

## Коли переглянути

При підключенні бази й хостингу уточнити середовище, міграції та бюджет. Оновлення інструментів приймати після перевірки сумісності та збірки.
