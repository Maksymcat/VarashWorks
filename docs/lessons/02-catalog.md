# Урок 02. Передай дані в одну картку

**Одна мета:** на сторінці `/masters` картка показує ім’я «Олексій (демо)» та спеціалізацію «Складання меблів», які приходять із батьківського компонента.

## Відкрий два файли

- `src/modules/catalog/components/master-card.tsx` — картка, яка отримуватиме дані.
- `src/modules/catalog/components/catalog-results.tsx` — компонент, який передаватиме ці дані.

## Що написати самостійно

1. У `master-card.tsx` опиши тип `MasterCardProps` із двома полями: `name` та `specialty`. Обидва — рядки (`string`). Почни тільки з цього пункту.
2. Додай props до функції `MasterCard`. Замість постійного тексту в `h3` покажи `name`, а в абзаці — `specialty`.
3. У `catalog-results.tsx` передай ці два значення в наявний `<MasterCard />`.

**Чому:** props — вхідні дані компонента, як аргументи звичайної функції. Картка відповідає за відображення, батьківський компонент вибирає, що їй передати. Згодом ту саму картку зможемо використати для різних майстрів.

## Як побачити результат

Запусти `npm run dev`, якщо сервер ще не працює, та відкрий `http://127.0.0.1:3000/masters`. На телефонній ширині можна поставити 390 × 844.

Зміни ім’я тільки в `catalog-results.tsx`. Якщо картка показала нове ім’я без редагування її розмітки — передавання даних працює.

Після цього запусти `npm run check`. Можна надіслати свою спробу ще до завершення; якщо є помилка, додай її текст.

**Готово, коли:** обидва значення приходять через props, видно на сторінці й проходять перевірку типів. Код цієї задачі асистент не реалізовує. Далі спочатку розберемо твою спробу, а вже потім візьмемо наступну задачу.
