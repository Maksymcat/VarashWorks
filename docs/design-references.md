# Напрям оформлення

Вибір користувача: білий фон, синій акцент, чіткі картки й фільтри. Пишемо mobile-first: спочатку невеликий екран, потім розширення через `min-width`.

Два приклади подібного типу сервісу для перегляду:

- [Taskrabbit](https://www.taskrabbit.com/) — зверни увагу, як користувачу пропонують почати пошук послуги.
- [Thumbtack](https://www.thumbtack.com/) — розглянь каталог послуг і представлення виконавців.

Це референси для обговорення, а не затверджений макет чи рекомендація користуватися цими сервісами. Не копіюємо чужі тексти, фото, бренд або оформлення. Остаточну типографіку й вигляд картки оберемо перед її наповненням; поточні стилі — основа каркаса.
